# EndOfLine
![Game image](https://imglink.cc/cdn/tosoxUGPoK.png)
These are the Unity files for my project EndOfLine, a puzzle RPG with hacking-inspired combat.
As of right now, I have only implemented the basic systems as a proof of concept, but I plan to continue working on this project.
You can play a demo right now on my itch (https://doublesharp.itch.io/endofline) or download the project and import it through Unity Hub (required to run a desktop version currently).
I appreciate any feedback/collaboration as I am still figuring out game balance/systems/bugs.

All code is written in C# by me without the help of generative AI, and all assets were drawn in Aseprite by me.

### Install Instructions
1. Clone the source code to your device using git.
```git clone https://github.com/malachihenson/endOfLine.git```
2. Import the file using Unity Hub (Unity Hub can be downloaded at https://docs.unity.com/en-us/hub/install-hub).
3. Once the import is finished, open the generated project in Unity.
4. From there, you can play in the editor or create a build (requires extra downloads and steps).
